### ✅ P0 级别修复（必须修复）

#### 1. 审批流程组件路径匹配逻辑修复

**问题描述**:
- 数据库菜单初始化文件中组件路径格式为 `plugins/dvadmin3-flow-web/src/xxx/index`
- 前端路由只匹配 `dvadmin3_flow/` 开头的路径
- 导致重新初始化后审批页面 404

**修复文件**: `web/src/router/backEnd.ts`

**修复内容**:
```typescript
// 新增兼容逻辑，支持两种路径格式
if (newComponent.startsWith("dvadmin3-flow-web/")) {
    // 已经是正确格式，无需处理
} else if (newComponent.startsWith("dvadmin3_flow/")) {
    // 旧格式转换
    newComponent = newComponent.replace("dvadmin3_flow/", "dvadmin3-flow-web/src/");
}
```

**状态**: ✅ 已修复

### ✅ P3 级别修复（优化修复）

#### 6. Sass 除法语法警告修复

**问题描述**:
- 使用废弃的 `/` 除法语法
- Sass 2.0 将移除此语法

**修复文件**:
- `web/src/views/system/login/component/mobile.vue`
- `web/src/views/system/login/component/account.vue`
- `web/src/views/system/login/component/oauth2.vue`
- `web/src/views/system/login/component/changePwd.vue`

**修复内容**:
```scss
// 旧语法（已废弃）
animation-delay: #{$i/10}s;

// 新语法
animation-delay: #{$i * 0.1}s;
```

**状态**: ✅ 已修复

---

#### 7. Vue 深度选择器语法警告修复

**问题描述**:
- 使用废弃的 `/deep/` 深度选择器
- Vue 3 推荐使用 `:deep()` 语法

**修复文件**:
- `web/src/views/plugins/dvadmin3-flow-web/src/wflow/design/form/config/FileUpload.vue`
- `web/src/views/plugins/dvadmin3-flow-web/src/wflow/design/form/config/ImageUpload.vue`

**修复内容**:
```scss
// 旧语法（已废弃）
/deep/ .el-form-item__label {
  padding: 0 12px 0 0;
}

// 新语法
:deep(.el-form-item__label) {
  padding: 0 12px 0 0;
}
```

**状态**: ✅ 已修复
