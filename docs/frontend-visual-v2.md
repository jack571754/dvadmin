# DVAdmin 视觉与交互改版 V2

本轮根据用户指定的五个网站重新设计，并同步落地到现有 Vue 管理后台。V1 原型已由 V2 替换；原文件和改动前页面位于项目外 `dvadmin-backups/design-v2-20261024-234220/`。

## 设计依据与取舍

| 参考 | 已核实的内容 | 本项目采用的方式 |
| --- | --- | --- |
| [Beautiful UI](https://www.beautifului.dev/) | Records Table、Filter Table、Sidebar Nav、Search 等组件示例 | 成员身份双行展示、轻量标签、状态视图、折叠导航、搜索与筛选反馈 |
| [BeUI](https://beui.dev/) | 动态 Tabs、Command Palette、Drawer、Toast 等交互组件 | 清晰的当前分区、搜索快捷入口、侧滑编辑与短暂状态反馈 |
| [Rare UI](https://www.rareui.com/) | 独立可组合的动画组件 | 借鉴小范围的控件细节，不将装饰性动画铺满高频工作区 |
| [Transitions](https://transitions.dev/) | 面板进入、按钮/状态切换、Toast 和骨架过渡示例 | 面板 220ms、提示 180ms、悬停/按压 150ms；支持 reduced-motion |
| [shadcn/ui](https://ui.shadcn.com/blocks) | 可组合组件与侧栏、表格等完整页面块 | 统一灰阶、边框、圆角与主次按钮，避免每块内容都争夺注意力 |

这些站点的组件能力是参考事实。具体配色、密度、布局和技术路线是本项目的设计判断。现有生产项目继续采用 Vue 3 + Element Plus + FastCrud，本轮没有直接安装 React 组件或依赖其远程资源。

## 视觉规范

- 浅灰导航、白色工作面、细分隔线，单一低饱和紫色强调当前选择与主要操作。
- 页面标题 25px，正文/列表以 12–14px 为主；说明、元数据逐级降低视觉权重。
- 桌面侧栏约 220–228px，顶栏约 56–58px；内容区保持统一对齐和 20–38px 间距。
- 表格使用轻量行分隔和悬停，不用密集竖线；成员信息把姓名与邮箱组合为一个阅读单元。
- 每页突出一个主要动作；危险操作二次确认，批量动作在选择记录之后出现。
- 亮/暗主题、紧凑密度和可见键盘焦点；减少动态效果偏好下关闭新增动画。

## 已实现的交互预览

地址：`http://127.0.0.1:8211/`，入口文件 `docs/prototypes/dvadmin.html`，样式和逻辑独立为 `styles.css`、`app.js`，不依赖外网字体、图标或 UI CDN。

1. **成员列表**：所有成员、待激活、已停用视图；按姓名/账号/邮箱即时搜索；部门、角色筛选；已选筛选可单独清除；行编辑、账号启停、选中后批量停用及确认；导出当前筛选为 CSV。
2. **成员编辑**：侧滑表单、必填和邮箱校验、角色/部门选择；取消修改前确认，保留列表上下文。
3. **角色授权**：菜单即时保存；操作和字段分区提交；失败保留字段草稿，菜单保存失败恢复原值；关闭时选择继续编辑或放弃；按角色保留已保存的字段示例。
4. **工作台**：与成员示例数据一致的概览、常用入口、动态记录和身份信息。
5. **全局交互**：命令搜索、Ctrl/Cmd+K、搜索快捷键 `/`、侧栏折叠、暗色模式、列表密度和窄屏布局。

示例数据及状态模拟入口置于产品之外的右下角预览工具中。预览不连接后端，不会修改真实账号和授权。未完成的配置/任务页面明确标记预览边界，不伪装成已接入的业务功能。

## 已接入真实后台

| 范围 | 本轮改动 |
| --- | --- |
| 默认布局 | 新增 scoped modern 样式，统一导航、顶栏、标签、表格、边框和焦点；新账号默认强调色调整为紫色，保留用户已有偏好 |
| 公共标题 | 新增类型化 PageHeading，统一标题、说明和操作槽 |
| 工作台 | 替换原示例统计和图表；展示当前账号、角色/部门、权限路由入口与真实消息加载/空/失败状态 |
| 用户管理 | 部门面板可搜索/清除，新增部门加载与失败反馈；全部/启用/停用视图；姓名/账号快捷搜索与按需展开高级筛选；保留原 CRUD、新增编辑和导入导出权限 |
| 角色页 | 统一标题与列表容器，授权抽屉适配窗口宽度及暗色表面，去掉内容面板固定 100vw/100vh |
| 通知 | 不再为“您已上线”这类登录回声弹出成功通知，保留其他系统与任务消息 |
| 国际化 | 新增简中、繁中、英文设计文案，沿用原语言加载机制 |

**边界：** 原型中的完整批量操作与未保存授权保护并未全部迁入真实角色页。真实后台本轮完成上述表格中的交付，原有授权 API 和分区保存语义不变；后续按 P1/P2 接入，不能把预览操作等同后端事务能力。
