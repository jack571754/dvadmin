# P2 用户操作与角色分配用户

日期：2026-10-25。承接 [角色授权批次](frontend-refactor-p2-roles-report.md)，继续推进 B15/B17/B19。未提交 Git，所有真实写入测试仅使用隔离 E2E 库。

## 用户操作

- 删除、重置密码从确认开始持有同一行锁，与状态开关共用；取消不报错，失败允许手动重试。确认后再次检查操作权限和发起会话，账号替换或授权撤销不能沿用旧确认执行写入。
- 用户新增/编辑关闭前检测修改并确认放弃；提交时禁止关闭。FastCrud 的 beforeClose 在当前依赖中按同步返回处理，确认后使用 wrapper 的直接关闭入口，不把 Promise 当作关闭许可。
- 导出使用当前搜索表单，修复原来传 ctx.row 导致筛选丢失的问题。异步任务响应显示下载中心链接，文件响应继续按真实文件下载。下载工具新增可选 onTask 回调，原调用方行为保留。
- 用户导入改用独立 UserImport 组件和共享请求入口，取消初始化时缓存 JWT 的上传 action。上传与导入防重，支持文件/导入失败反馈；失败保留文件，已上传的 URL 供主动重试复用。
- 上传与导入之间再次检查会话与权限；离开页面清理文件状态，旧响应不能继续发起后续导入。模板下载有失败反馈；成功导入后刷新列表。

## 角色分配用户

- 授权用户弹层复用角色授权上下文；接口请求捕获固定角色和移入/移出用户副本，提交期间不能关闭或操作其他授权。
- 弹层标明立即保存。失败回到已确认分配，旧角色请求不更新新角色用户；更新后的已分配人数与弹层保持一致，字段草稿不被覆盖。
- 可选用户按页读取，不再固定截断 999 条；整个分页读取绑定原会话，重复页没有进展时终止并提示。
- 服务端 set_role_users 增加现有 CustomPermission 检查，完整校验方向和用户 ID 后再修改；目标角色使用既有 get_object 数据范围过滤。没有新增角色或数据库迁移。

全量回归过程中定位到构建与测试的环境干扰：旧 Vite 配置在启动/构建时改写 `public/version-build`，并行构建会触发开发页面整页刷新，导致登录/导航断言失败。本批将版本标记改为 Rollup 构建输出资产，保留 `dist/version-build` 契约；已验证构建后 public 源文件内容与时间戳均不变。最终构建与浏览器回归串行执行，不放宽断言或启用失败重试掩盖问题。版本检查仍等待路由及 WebSocket 生命周期的后续任务尚未完成。

新增导入/导出和删除/重置故障场景使用浏览器拦截，不代表真实 Excel 全格式导入、Celery 队列或生产文件链路已验收。上传成功而导入失败会保留服务端上传文件；本批不擅自删除服务器文件。网络不确定时服务端可能已经执行，手动重试前应核对结果。
