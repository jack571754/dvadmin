# P2 角色授权上下文与数据范围

日期：2026-10-25。承接用户表单批次，推进 B17/B18/B19；所有写入测试针对隔离 E2E 数据库，未提交 Git。

## 行为

- 抽屉以角色和菜单为上下文；旧菜单/角色读取结果、旧写入回调不再覆盖当前内容。初始树勾选只读取状态，不触发授权写入。
- 菜单与接口操作立即保存，字段修改单独保存。字段有草稿状态、放弃入口，切换菜单、关闭抽屉或路由离开前确认放弃；写入期间禁止切换和关闭。
- 字段失败保留草稿；菜单及按钮失败回到已确认状态。移除原来可能跨菜单提交的防抖队列，单个/分组操作捕获固定角色、菜单和请求副本并防重。
- 数据范围弹窗使用副本；取消不改原记录，失败保留弹窗与选择。按钮刷新保留同菜单尚未保存的字段草稿。部门读取支持失败提示和重试，迟到结果不能写到其他角色。
- 新授权默认仅本人范围，不再沿用全账号共用的 Local 默认范围和自定义部门。菜单、字段、按钮、数据范围分别核对相应操作权限。
- 服务端授权 action 原来只要求登录。本批按现有 role:* 权限值检查操作，兼容 fixture 中旧 API 路径拼写差异；超管保留原行为，只读/受限角色不能绕过界面直接授权。
- 批量按钮与字段写入先校验整份输入，再在各自事务中保存。禁止混入其他菜单按钮；新建批量授权保存自定义部门，重复勾选保留已有单独配置的范围。
- 数据范围更新用 set 替换部门，不再累积旧选择；范围非自定义时清空部门。自定义数据过滤增加当前接口按钮限制，避免其他操作的自定义范围扩大当前查询结果。
